# Bloom ✦

Трекер привычек и задач для телефона. Все данные хранятся только в браузере (`localStorage`), резервная копия — через ⚙️ → Экспорт / Импорт.

**Сайт:** https://ifukkatsumi.github.io/bloomtracker/

## Структура

Без сборщика и зависимостей — обычные HTML, CSS и ES-модули.

```
index.html          разметка и модальные окна
css/
  base.css          переменные (розовая тема по умолчанию), фон, каркас, тост
  themes.css        светлая, тёмная, сиреневая, фиолетовая темы
  layout.css        шапка, верхняя карточка, нижняя панель, FAB
  components.css    карточки, сворачиваемые разделы, режим сортировки
  modals.css        модальные окна, настройки, календарь
  marathon.css      вкладка «Марафон»
js/
  main.js           точка входа: вкладки, FAB, синхронизация между экземплярами
  storage.js        ключи и чтение / запись localStorage
  state.js          данные приложения и нормализация старых форматов
  dates.js          работа с датами, склонения
  stats.js          серии, проценты, срок действия привычек
  ui.js             стек модалок, тосты, жесты, делегирование кликов, сворачивание
  sortable.js       перетаскивание (touch + mouse)
  topcard.js        верхняя карточка для каждой вкладки
  habits.js         привычки: список, сортировка, календарь истории
  tasklogic.js      разделы задач и правила подзадач (без DOM)
  tasks.js          задачи: разделы, подзадачи, архив, свайп, сортировка
  marathonplan.js   календарь марафона: 9 блоков, 60 дней (без DOM)
  marathon.js       вкладка «Марафон»
  settings.js       настройки и темы
  backup.js         экспорт / импорт JSON, проверка истории
```

## Хранилище

| Ключ | Что внутри |
|---|---|
| `bloom_habits_v2` | привычки, история `{ 'YYYY-MM-DD': true }` |
| `bloom_tasks_v2` | задачи и подзадачи (`parentId`), порядок в `order` |
| `bloom_marathon_v1` | задачи марафона (`week`: `null` или 1–9, `category`: id категории) |
| `bloom_mcats_v1` | категории задач марафона (до 9) |
| `bloom_ui_v1` | свёрнутые разделы |
| `bloom_theme` | тема оформления |

Резервная копия — версия 4 (марафон, его категории и тема); старые копии импортируются без потерь.

Кнопки в разметке не используют `onclick`, а помечаются `data-action="…"`; обработчики регистрируются через `onAction('…', fn)` в `ui.js`.

## Запуск локально

ES-модули не работают при открытии файла двойным кликом (`file://`), нужен любой локальный сервер:

```bash
python3 -m http.server 8000
```

и открыть http://localhost:8000.
